# BEYOND THE FRAME — 웹 포스터

2026 한국폴리텍 서울정수캠퍼스 시각디자인과 졸업전시(11.17 – 11.18, 제3공학관 2층) 인터랙티브 3D 포스터.

- 전시장 안에 포스터가 떠 있고, 포스터를 누르면 유리가 살짝 깨지면서 균열을 따라 밝은 코드가 빠져나갑니다.
- 빛나는 금빛 나비(`butterfly-gl.js`)가 전시장을 날아다니고, 누를 때마다 깨진 자리에서 한 마리씩 날아 나옵니다.
- 포스터에 인쇄된 코드 줄이 액자 밖으로 이어져 금빛으로 흘러나옵니다.
- 바닥은 물처럼 일렁이며 전시장을 비추고, 누른 자리 아래로 물결이 퍼집니다.
- 로고와 날짜는 포스터에서 윤곽을 따서 3D 글자로 세웠습니다.
- 1080 × 1920 세로형 키오스크 기준으로 배치했습니다. 다른 화면에서 키오스크 비율로 미리 보려면 주소 끝에 `#kiosk`를 붙이세요.

파일: `index.html`(전체 코드) · `art.webp`(포스터 원본 2048px) · `butterfly-gl.js`(금빛 나비) · `wing.webp`(WebGL2가 없을 때 쓰는 나비 날개) · `cracks.json`(포스터 균열 좌표) · `type.json`(로고·날짜 벡터)
